        \textit{Note:} This figure plots the estimated dynamic response of family flows to a family's first livestream. The estimates are the coefficients from the two-way fixed effects (TWFE) difference-in-differences model. The horizontal axis represents quarters relative to the first livestream, where Quarter 0 is the event quarter. The quarter prior to the event (Quarter -1) serves as the baseline period, andits coefficient is normalized to zero. The solid blue dots represent the point estimates, and the vertical lines indicate the 95\% confidence intervals around these estimates. For visualization, the endpoints of the event window are binned: the estimate at Quarter +4 aggregates all periods from Quarter +4 onwards, and the estimate at Quarter -4 aggregates all periods from Quarter -4 and earlier. See Appendix~\ref{tab:vardefs} for detailed variable definitions.
